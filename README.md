# E-Commerce Sales Analysis | Power BI Dashboard

## 📌 Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Power BI. The dashboard helps explore sales performance, product categories, customer purchasing patterns, and business trends through interactive visualizations.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and calculations

## 📊 Key Analysis
- Overall Sales and Profit Analysis
- Category-Wise Sales Performance
- Product Performance Analysis
- Customer and Regional Analysis
- Sales Trends and Business Performance
- Interactive Filters and KPI Cards

## 🎯 Project Objectives
- Understand overall e-commerce sales performance.
- Identify high-performing products and categories.
- Explore customer and regional sales patterns.
- Present key business metrics through an interactive dashboard.
